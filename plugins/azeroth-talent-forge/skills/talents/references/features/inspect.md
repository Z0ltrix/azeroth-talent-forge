# Inspect

Command: `inspect --code STRING [--level LEVEL]`

Read-only operation. Reports class/spec, requested validation level, hero subtree, observed tree
hash, every selected node, Entry ID, talent name, purchased/granted ranks,
choice index, description/effect, and structural validation violations.
`source_patch_verified` distinguishes an exact bundled-build hash from an
accepted zero-hash input. It describes the string; it does not recommend it or
simulate combat.
